Analysis rules & limitations

BLQ values are null in the NCA input; underlying model values are never used. Equality to LLOQ is quantifiable. For IV bolus, predose is excluded. When 0+ is not observed, C0 for AUC integration is back-extrapolated from the first two quantifiable postdose samples if the initial log slope is negative (otherwise the first quantifiable concentration is used). The estimated C0 is excluded from observed Cmax and λz regression. PO uses a zero origin and zero for leading BLQ for AUC only. Trailing BLQ is excluded. Intermediate BLQ blocks AUC unless explicit endpoint bridging is enabled.

Automatic λz fits unweighted log concentration versus actual time using contiguous quantifiable suffixes ending at the last quantifiable sample, with ≥3 points. PO excludes observed Tmax; IV may include its peak. No regression crosses an intermediate BLQ gap. Highest adjusted R² wins; fits within 0.0001 of the best prefer more points. Manual fits use the checked eligible rows, which may omit the final sample; extrapolation still uses the last measured quantifiable concentration, not a fitted concentration. A negative slope is required.

This is an exploratory implementation, not validated against Phoenix WinNonlin. High R² does not demonstrate a terminal phase. The PO comparison uses the apparent asymptotic terminal half-life, including flip-flop; disposition half-life is shown separately. Near-equal rates or early two-compartment sampling may not yet reflect that asymptote.

Model assumptions & interpretation ＋

Linear, time-invariant pharmacokinetics with first-order elimination from the central compartment. Oral doses have first-order absorption, constant bioavailability, and no lag time. Repeated doses use superposition. Concentrations represent the central compartment.

Disposition half-life describes elimination/distribution. Apparent oral half-life uses the slower of absorption and terminal disposition; a longer apparent half-life indicates absorption-limited (flip-flop) kinetics. For zero dose or F = 0 these are model rate descriptors, not an observable concentration slope. Log scale omits true zero values.
